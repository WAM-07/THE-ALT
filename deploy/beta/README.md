# The ALT beta server

A public test copy of The ALT Ecosystem for the team (owner's decision, 2026-10-20): the four backend services and
the two websites on one Ubuntu 24.04 server (Oracle Cloud Always Free, Ampere A1, user `ubuntu`; any Ubuntu VM with
the `alt_beta` SSH key and a sudo user works), with HTTPS from Caddy, and the ALTER and ALTERA apps built to use it.
On Oracle, ports 80 and 443 must also be opened in the subnet's security list (setup.sh opens the VM's own firewall).

| Part | On the server |
|---|---|
| Gateway, ALT Core, ALTERA API, ALTAR API | `deploy/beta/start.mjs` under systemd (`alt-beta`), production mode, ports on 127.0.0.1 |
| ALTAR web and the ALT Command Centre | the same, from their production builds (`next build`, `next start`) |
| Database | the server's PostgreSQL (`alt_beta`) |
| Blockchain | a private test chain (31337), saved block by block in `/var/lib/alt/chain.jsonl` and replayed on restart. Not a public network: nothing is on polygonscan. |
| Test POL | every new account gets 100 test POL automatically (`STARTER_TEST_POL=100`); it has no value |
| Files | `/var/lib/alt/uploads` |
| Email codes | Gmail SMTP (app password) |

## Files on the server

- `/etc/alt/beta.env`: public URL, SMTP, LLM keys, demo password, `STARTER_TEST_POL` (root and `alt` only).
- `/etc/alt/db.env`: the database URL (generated by `setup.sh`).
- `/var/lib/alt/dev-secrets.json`: the token signing key, the encryption key and the service key (generated on first start). Losing it locks every wallet and 2FA secret, so keep it with the database backup.

## Commands

```bash
# once, as root on a new Ubuntu 24.04 droplet
bash setup.sh <ip-with-dashes>.sslip.io

# from the repository root on a PC (Git Bash); needs ~/.ssh/alt_beta and .env.beta filled in
bash deploy/beta/configure.sh        # writes /etc/alt/beta.env on the server from .env.beta
bash deploy/beta/deploy.sh --seed    # first time: code, builds, the demo story, start
bash deploy/beta/deploy.sh           # later: new code, restart (data and chain are kept)
powershell -ExecutionPolicy Bypass -File deploy/beta/build-apks.ps1   # ALTER-beta.apk and ALTERA-beta.apk in deploy/beta/apk/

# on the server
journalctl -u alt-beta -f            # logs
systemctl restart alt-beta
```

Starting over (wipes the beta's accounts, AIs and chain): stop `alt-beta`, drop and recreate the `alt_beta`
database, delete `/var/lib/alt/chain.json*`, then `deploy.sh --seed`.
